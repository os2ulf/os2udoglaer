These modules are project-maintained copies of modules from Drupal.org, adjusted
for Drupal 11 compatibility. The upstream releases used during the upgrade did
not declare Drupal 11 support, so copies were retained here to preserve the
project's existing functionality.

The original module names are unchanged to preserve configuration and permissions.
Each module's UPSTREAM.txt records its source release. Monitor upstream releases
and security fixes, and return to maintained upstream packages when suitable
compatible releases are available.
